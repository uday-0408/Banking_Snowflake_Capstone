Banking Analytics Project — Overview1. What This Project IsWe are building a data pipeline and reporting layer for a retail bank. The goal is to take raw data about transactions, loans, and customer complaints, clean it up, and turn it into a small set of trustworthy numbers (KPIs) that the business can use to make decisions.This document gives you the big picture before you start working on any individual task.2. Scope of WorkIn ScopeBringing in data from three areas: transactions/payments, loans, and customer complaints. A single CSV containing all data combined together will be provided.Cleaning and organizing that data so it's consistent and reliable.Building a final ('Gold') layer of tables that directly answer the business questions in Section 5.Making sure the pipeline can run on a schedule, catch errors, and be re-run safely.3. Tools We're UsingThree tools work together:Airflow — schedules and runs the pipeline steps in the right order, at the right time (e.g., "run the cleanup job every night, then run the KPI job after it finishes").dbt — where we write the actual transformation logic — the SQL that cleans raw data and builds the KPI tables. Think of dbt as "the recipes."Snowflake / MS SQL — where the data actually lives — the database that stores every layer, from raw data to the final KPI tables.4. Architecture — How Data FlowsData moves through four layers, getting cleaner and more business-ready at each step:1. Source systems — the bank's own systems that record transactions, loans, and complaints as they happen. CSVs will be provided instead.2. Raw layer — data is copied in exactly as-is, no changes. This is our safety net — if anything downstream breaks, we can always start over from here.3. Silver layer — data gets cleaned up: fixing types, standardizing values like loan status or complaint priority, handling missing data, and — the main thing — implementing data modeling.4. Gold layer — the final, business-ready tables: one for each KPI (or group of related KPIs) in Section 5 below. This is what reports and dashboards will read from.5.
